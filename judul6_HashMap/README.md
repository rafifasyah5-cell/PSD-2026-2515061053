Program ini berfungsi sebagai sistem manajemen data digital yang dirancang untuk mengoptimalkan efisiensi proses administrasi. Melalui sistem ini, pengelola tidak perlu lagi menelusuri informasi secara manual yang memakan banyak waktu. Hanya dengan memasukkan Nomor Pokok Mahasiswa (NPM), sistem akan langsung menarik dan menampilkan biodata lengkap mahasiswa secara instan tanpa perlu memindai seluruh pangkalan data dari awal. Secara keseluruhan, tujuan utama program ini adalah memastikan proses registrasi dan pencarian identitas berskala besar berjalan jauh lebih cepat, terstruktur, dan akurat.

Pada fungsi ini user tampilkan pada bagian menu, dan user diminta untuk menginputkan menu nomor berapa, yaitu 1 untuk memasukkan data, 2 untuk mencari data, serta 3 untuk keluar dari program.

<img width="577" height="311" alt="Screenshot 2026-06-06 090111" src="https://github.com/user-attachments/assets/615b0c46-8e2f-4fac-b41e-e9d9f7b4ccbc" />

Jika user memilih menu nomor 1 maka user diminta untuk memasukkan data mahasiswa seperti NPM, Nama, Jurusan, dan Organisasi dari mahasiswa yang akan diinputkan ke database.

<img width="760" height="292" alt="Screenshot 2026-06-06 090232" src="https://github.com/user-attachments/assets/e1c3686c-ce4c-44ea-9961-4a97f13c2ee9" />

Jika user memilih menu nomor 2 maka user diminta untuk memasukkan key atau NPM dari mahasiswa yang akan dicari, jika sesuai dan ada maka sistem akan menampilkan data mahasiswa yang bersangkutan

Jika user memilih menu nomor 3 maka program akan berhenti dan selesai, jika input tidak valid maka program akan menampilkan pilihan tidak valid
